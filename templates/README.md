# دليل القوالب الحتمية (Tier A)

القوالب الحتمية هي **المسار المفضل** في المصنع.

هي منتجات ثابتة جاهزة تُبنى بدون الاعتماد على نماذج الذكاء الاصطناعي. لذلك فهي:
- مضمونة الجودة
- مجانية تمامًا (لا تستهلك أي رصيد API)
- سريعة وموثوقة
- سهلة الصيانة والتوسيع

---

## معايير القالب الإلزامية

يجب أن يستوفي أي قالب جديد **كل** الشروط التالية:

| المعيار | التفاصيل |
|---------|----------|
| **الحجم** | الملف النهائي < 80 KB (يفضل < 50 KB) |
| **التقنية** | HTML + CSS فقط (يُسمح بـ JavaScript خفيف جدًا ومضمن) |
| **لا مكتبات خارجية** | ممنوع CDN أو ملفات خارجية |
| **دعم العربية** | اتجاه RTL كامل + خطوط مناسبة للنص العربي |
| **متوافق مع الهاتف** | تصميم Mobile-first |
| **يعمل بدون إنترنت** | بعد التحميل الأول |
| **وضوح** | عنوان واضح + وصف موجز في أعلى الصفحة |

---

## هيكل القالب المقترح

كل قالب يوضع في مجلد خاص به داخل `templates/`:

```text
templates/
└── اسم-القالب/
    ├── index.html      # الملف الرئيسي
    ├── style.css       # (اختياري إذا كان مضمنًا)
    └── meta.json       # معلومات القالب (الاسم، الوصف، الفئة)
```

### مثال بسيط لـ `meta.json`:

```json
{
  "name": "حاسبة بسيطة",
  "description": "حاسبة أساسية للعمليات الأربع",
  "category": "أداة حسابية",
  "version": "1.0"
}
```

---

## كيفية إضافة قالب جديد

1. أنشئ مجلدًا جديدًا تحت `templates/`.
2. ضع ملف `index.html` يلتزم بالمعايير أعلاه.
3. أضف `meta.json`.
4. افتح Pull Request ووضّح أن القالب يلتزم بمعايير الجودة.

القوالب الحتمية لها أولوية في الدورة الأسبوعية لأنها الأكثر استقرارًا وتكلفة صفر.
