# Changelog

All notable releases of the Weekly Micro-Product Factory.

## [1.0.0] — 2026-09-17

### Production maturity

- Deterministic templates + optional AI agent pipeline
- Community voting (GitHub Reactions) + issue intake
- Adversarial critic + objective diversity score
- Bilingual AR/EN (`locales/`, `FACTORY_LANG`)
- Optional Telegram notifications
- Contributor reputation (`catalog/contributors.json`)
- Stats dashboard with quality metrics
- Unit tests (`pytest`) for triage, i18n, diversity analyzer
- Developer docs: `docs/AGENTS_API.md`, fork guides
- Root landing page `index.html`

Semantic Versioning: **MAJOR.MINOR.PATCH**
- MAJOR: breaking workflow/agent contracts
- MINOR: new agents, integrations, templates
- PATCH: fixes, docs, tests
