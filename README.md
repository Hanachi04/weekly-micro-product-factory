# مصنع المنتجات المصغرة الأسبوعي الذاتي
**Autonomous Weekly Micro-Product Factory**

نظام مفتوح المصدر، **مجاني بالكامل**، وقابل للتشغيل والمراقبة عبر الهاتف الذكي فقط.

ينتج المصنع منتجًا رقميًا ثابتًا (Static Micro-product) واحدًا على الأقل كل أسبوع باستخدام GitHub Actions + GitHub Pages، مع مزيج من القوالب الحتمية ووكلاء ذكاء اصطناعي متخصصين، وضمانات صارمة للجودة والأمان والتنوع.

---

## الرؤية

تمكين أي فرد أو مجتمع عربي من إنشاء منتجات رقمية قيمة بانتظام، دون حاجة لميزانية أو أجهزة متطورة، مع الحفاظ على الجودة والتنوع والأمان.

## المبادئ الأساسية

| المبدأ | الوصف |
|--------|-------|
| **مجاني بالكامل** | لا يستخدم أي خدمة مدفوعة. كل شيء ضمن الحدود المجانية لـ GitHub. |
| **قابل للتشغيل عبر الهاتف** | المراجعة والموافقة والمراقبة مصممة لتعمل بسلاسة على الأجهزة المحمولة. |
| **عام وشفاف** | المستودع عام، والأفكار المقدمة تُعامل كبيانات عامة. |
| **آمن وموثوق** | لا يُنشر أي محتوى مولَّد دون اجتياز بوابات تحقق متعددة. |
| **تنوع مضمون** | وكلاء متخصصون يمنعون تشابه المنتجات مع الأسابيع السابقة. |

---

## كيف تقدم فكرة منتج؟ (من هاتفك)

1. اضغط على تبويب **Issues** في أعلى الصفحة.
2. اختر **New issue**.
3. اختر قالب **فكرة منتج جديد**.
4. املأ الحقول البسيطة (العنوان، الوصف، الفئة).
5. أرسل.

سيتم فرز الفكرة تلقائيًا وإضافتها إلى قائمة الانتظار للدورة الأسبوعية.

```text
├── catalog/               # فهرس المنتجات والتحليلات

```
