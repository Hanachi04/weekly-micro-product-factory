# مصنع المنتجات المصغرة الأسبوعي الذاتي

مصنع مفتوح المصدر ينتج **منتجات رقمية عربية ثابتة** (HTML واحد، بدون إنترنت، أقل من 80KB) كل أسبوع — يدوياً أو تلقائياً من أفكار المجتمع عبر GitHub Issues.

## كيف تقدّم فكرة؟

### التصويت المجتمعي

بعد قبول الفكرة يُفتح **تصويت بـ 👍** على تعليق خاص.
كل يوم اثنين (التشغيل الأسبوعي) يختار المصنع الفكرة **الأعلى تصويتاً** وينتجها.
بعد النشر يُغلق الـ Issue بوسم `produced` مع رابط المنتج.

### لوحة الإحصائيات

صفحة حية: [`/stats/`](./stats/) — عدد المنتجات، نسبة الجيل الذكي، آخر الإصدارات، وأنماط التنوع.


1. افتح تبويب **Issues** في هذا المستودع.
2. اختر قالب **فكرة منتج جديد**.
3. املأ العنوان والوصف والفئة (من الهاتف بسهولة).
4. أرسل.

### ماذا يحدث بعد الإرسال؟

| النتيجة | ماذا ترى |
|---------|----------|
| **مقبولة** | تعليق تأكيد + وسم `approved` + فتح تصويت 👍 للدورة الأسبوعية |
| **مرفوضة** | تعليق مهذب يشرح السبب + وسم `rejected` + إغلاق الـ Issue |

الرفض الشائع: روابط خارجية، أكواد تنفيذية، أو عنوان/وصف ناقص.  
عدّل الفكرة وقدّم Issue جديداً في أي وقت.

> الحد اليومي: حتى **5 أفكار/يوم** لحماية موارد Actions المجانية.

## مسار الإنتاج

```
Issue مفتوح
  → triage_agent (فرز + أمان)
  → diversity_agent (بطاقة تنوع)
  → content_agent (نصوص عربية)
  → design_agent (HTML من قالب + قيود)
  → validate + publish
  → products/weekly/<week_id>/
```

المسار الحتمي (قوالب جاهزة بدون ذكاء اصطناعي) يبقى احتياطياً عند تعطيل `enable_ai` أو فشل المزودين.

## التشغيل اليدوي

من **Actions → weekly-build → Run workflow**:

- اختر قالباً: `calculator` / `landing-page` / `weekly-tracker`
- أو فعّل `enable_ai` مع عنوان ووصف الفكرة

## هيكل المستودع

```
agents/           وكلاء الفرز والتنوع والمحتوى والتصميم
templates/        قوالب حتمية خفيفة (RTL، بدون CDN)
products/weekly/  المنتجات المنشورة + meta.json
catalog/          فهرس تراكمي
.github/workflows/
  weekly-build.yml   خط الإنتاج
  issue-intake.yml   استقبال الأفكار من Issues
```

## أسرار مطلوبة (للمسار الذكي)

في Settings → Secrets:

- `GEMINI_API_KEY` و/أو `GROQ_API_KEY` و/أو `MISTRAL_API_KEY`

بدونها يعمل المصنع بالقوالب الحتمية وبطاقات احتياطية.

## المبادئ

- صفر تكلفة تشغيل (GitHub Actions + نماذج مجانية)
- عربي أولاً وRTL
- بدون مكتبات خارجية في المنتج النهائي
- تنوع مضمون بين الأسابيع
- أمان: لا روابط، لا أكواد تنفيذ، لا أسرار في الأفكار
